# Carlos Cabrera language lessons website

This is a complete static website for GitHub Pages. It uses ordinary HTML and
CSS, with no framework, database, tracking scripts, or paid dependencies.

## Files

    index.html
    styles.css
    favicon.svg
    robots.txt
    sitemap.xml
    images/spanish-with-carlos-hero.webp
    images/spanish-with-carlos-hero.jpg

The header uses Spanish with Carlos and the tagline Spanish & Catalan for Life
in Spain. The SEO title is Online Spanish Lessons for English Speakers |
Spanish with Carlos.

## Upload to GitHub Pages

1. Open the public repository named spanishwithcarlos.github.io.
2. Open the repository and select Add file, then Upload files.
3. Upload everything inside this folder. Keep index.html at the top level.
4. Commit the files to the main branch.
5. Open Settings, then Pages.
6. Select Deploy from a branch, main, and /(root).
7. Save and wait for the published address to appear.

## Update the website

Edit index.html for wording and content. Edit styles.css for colors, type, and
layout. Commit a change on GitHub and Pages will publish the new version
automatically.
